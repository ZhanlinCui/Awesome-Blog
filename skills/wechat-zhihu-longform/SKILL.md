# 中文长文成稿（wechat-zhihu-longform）

## 触发
中文栈大纲冻结后，撰写非代码型正文段落；也用于把技术段落“翻译”成好读的中文叙述。

## 步骤
1. **前 3 行留人**：用具体场景、具体问题或具体反差开头；禁止宏大开场与背景铺陈开场。
2. **一段一义、短段为主**：手机端 1–4 行一段；小标题制造节奏；长论证拆成“观点→证据→解释→小结”。
3. **术语成人话**：专业词首次出现给一句大白话+一个类比；但代码标识符/API/库名/命令保留英文原名，不硬翻。
4. **纯中文纪律**：删掉无必要的中英夹杂（“进行一个 confirm”“这个 point 很 key”）；
   保留业内通用英文词（如 benchmark、cache）时全篇用法统一。
5. **三视角自检**：作者（我真这么想吗）、编辑（逻辑顺吗、有水话吗）、读者（跟得上吗、信吗、与我有关吗）。
6. **配图纪律**：引用真实图片文件或 Mermaid；没有图就不要留 `[图1：示意]`；图注写结论。
7. **评论区预演**：列出读者最可能的 3 个质疑，在正文中提前回应（反证思维）。

## 输出契约
- 中文分节草稿；待核查/待补图清单。

## 质量门
- 前 3 行无具体钩子；存在硬伤性中英夹杂；出现虚构“网友/案例/数据”；图占位未解决 → BLOCKED。

## 不做什么
- 不写“震惊体”和情绪煽动；不堆砌“干货/本质/底层逻辑”等空词；
- 不产出任何平台发布指令或平台操作内容——交付止于本地稿件。
