# 发布前检查清单（Preflight Checklist）

> 本清单的“发布前”指**把本地成稿交付给作者、由作者自行手动上传之前**。
> 套件本身不执行任何平台登录或自动上传。

## A. 事实与证据（任一不过 = BLOCKED）
- [ ] 每条事实/数字主张能在 claims_registry 找到，且 source_ids 指向真实存在的来源
- [ ] 关键事实具备独立印证，或已降级为单源表述
- [ ] 聚合商与原始出处未被当成两个独立来源
- [ ] 预测/估算均带有生产方、时间、假设或区间，未伪装成事实
- [ ] 反证尝试已记录；争议点保留了冲突与不确定性

## B. 技术校验
- [ ] 所有代码块、命令已实际运行通过（或已显式标注“未经运行验证”及原因）
- [ ] 版本号、参数、API 名、文件名经过核对
- [ ] benchmark 数字有环境、配置、日期与复现实验说明

## C. 研究痕迹剥离
- [ ] 无 S0xx/C0xx 等内部 ID
- [ ] 无本地绝对路径、台账文件名、“见登记册”类审计标签
- [ ] 无 [CITATION NEEDED] / TODO / 待补占位（补证据或删主张，二选一）

## D. 编辑与合规
- [ ] AI 腔清单逐项检查（见 editor-polish-zh/en）
- [ ] 术语全文一致；中文稿无不必要中英夹杂
- [ ] 图片/引用内容许可已确认，来源已标注
- [ ] 无越界的医疗/法律/投资确定性结论
- [ ] 评分/SEO 相关表述未对外做出效果承诺

## E. 交付物
- [ ] 产物为本地 Markdown/HTML 文件，路径：
- [ ] 平台适配（标题风格、排版、篇幅、代码块呈现）仅体现为稿件格式
- [ ] 已明确告知：上传/发布动作由作者本人手动完成

## 脚本验证记录
- [ ] `python3 scripts/validate_evidence_ledger.py ...` 通过
- [ ] `python3 scripts/audit_claim_citations.py ...` 通过
- [ ] `python3 scripts/market_sizing.py ...` 通过（涉市场测算时）
- [ ] `python3 scripts/preflight.py ...` 退出码 0
