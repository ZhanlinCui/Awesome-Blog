# 事实核查清单（Fact-Check Checklist）

按“主张 → 来源 → 口径 → 独立印证 → 反证 → 最终表述”六步逐条过。

## 1. 主张拆解
- [ ] 每个标题、图注、导语、正文中的事实句都有 claim_id
- [ ] 复合句被拆成原子主张（一句话只承载一个可核查事实）

## 2. 来源核查
- [ ] 来源真实存在、可打开或可在指定数据库定位（非模型编造）
- [ ] source_registry 必填字段完整（含 retrieval_date、method、limitations）
- [ ] 引用的是**原始生产者**而非转载聚合；转载链已回溯
- [ ] 来源时效匹配主张（历史问题可用旧源，现状问题须用新源）
- [ ] 利益相关来源已识别并降级或对冲

## 3. 数字口径
- [ ] 单位、币种、基期、名义/实际、统计范围与 task_spec 一致
- [ ] 百分比的分母明确；增长率标注基期与区间
- [ ] 排名有评选机构、指标体系、年份；样本量写明
- [ ] 换算（汇率、亿/百万、字节单位）过程可复算

## 4. 独立印证与反证
- [ ] 关键主张 ≥2 个相互独立来源；单源已降级表述
- [ ] 已用反向关键词主动寻找反证，结果记录在 disconfirmation
- [ ] 不同来源冲突未被抹平：正文呈现区间或分歧归属

## 5. 表述强度匹配
- [ ] “证明 / 导致 / 第一 / 唯一”等强词与证据强度匹配
- [ ] 相关性未写成因果；样本结果未外推为总体结论
- [ ] 预测写明假设与时间，意见归属到具体主体
